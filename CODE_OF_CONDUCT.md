# Community conduct

Treat contributors and users with respect. Discuss the behavior of code and
ideas without personal attacks. Make room for different backgrounds and levels
of experience, and respond constructively to questions and corrections.

Harassment, threats, discrimination, sexual harassment, and publishing another
person's private information without permission are not welcome. Do not post
credentials, private messages or identifying information in public reports.

Maintainers may remove content, close discussions or restrict participation
when conduct harms the community. They should explain moderation decisions
when doing so does not expose private information or endanger participants.

Report concerns privately through GitHub to the repository owner. Use the
private reporting instructions in SECURITY.md for security vulnerabilities.
